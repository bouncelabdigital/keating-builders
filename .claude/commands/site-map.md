# /site-map — Site Architecture Planning & Audit

You are a senior information architect planning or auditing the site structure for the Keating Builders website.

---

## Mode

Detect the current project state:
- **If no pages exist yet:** Run in **Planning Mode** — design the ideal site architecture from scratch
- **If pages exist:** Run in **Audit Mode** — evaluate the current structure and recommend improvements

---

## Planning Mode

### Step 1: Define Business Goals
The site architecture should map directly to:
1. The primary conversion goal (contact/quote request)
2. The services Keating Builders offers
3. The trust-building journey a prospective client takes

### Step 2: Proposed Site Map

Build a site map covering:

**Primary Navigation (top-level pages)**
- Home
- Services (may be a dropdown or flat page)
- Projects / Portfolio
- About
- Testimonials / Reviews
- Contact

**Service Sub-pages** (one per major service type):
- Residential Construction
- Commercial Construction
- Renovations & Extensions
- [Any other specific services]

**Secondary Pages** (in footer or utility nav):
- Privacy Policy
- Terms of Service
- Sitemap (HTML)

**Optional (if scope allows):**
- Blog / News (excellent for SEO)
- FAQ Page (captures question-based search queries)
- Careers / Join Our Team

### Step 3: User Journey Mapping
Map the primary user journey:
1. Arrives on homepage → understands what Keating Builders does and where
2. Browses services → finds their specific need
3. Views portfolio → sees quality proof
4. Reads testimonials → trust is built
5. Clicks CTA → lands on contact form → submits

Mark which pages are critical to this journey.

### Step 4: Navigation Architecture
- Recommend primary nav items (max 6–7)
- Recommend footer columns and links
- Note any breadcrumb requirements for deep pages

### Step 5: Output
Produce:
1. A visual text-based site map (indented tree structure)
2. For each page: its URL slug, primary purpose, and primary CTA
3. A navigation structure recommendation

---

## Audit Mode

If pages already exist, evaluate:
- Are all pages reachable within 2–3 clicks from the homepage?
- Are there orphaned pages (not linked from anywhere)?
- Is the navigation hierarchy logical?
- Are URL slugs clean, keyword-rich, and consistent?
- Are there any gaps in content coverage vs. what competitors offer?

Report issues and produce a revised recommended site map.
