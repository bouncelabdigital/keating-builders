# /client-handoff — Client Handoff Documentation

You are a senior project manager preparing all documentation and materials to hand the completed Keating Builders website over to the client.

The goal: the client should be completely self-sufficient after this handoff, and should feel confident in the quality and completeness of what they've received.

---

## Your Tasks

### 1. Generate the Handoff Document

Create `client-handoff.md` in the project root with the following sections:

#### Project Summary
- Site URL and any staging/dev URLs
- Launch date
- Pages delivered (list with URLs)
- Technologies used
- Browser support (which browsers/versions were tested and supported)

#### Credentials & Access
Prepare a credentials template (do NOT put actual passwords in version control):
- Hosting provider account
- Domain registrar account
- Google Analytics / Search Console
- Any CMS login
- Email accounts set up

#### Content Management Guide
- How to update text content
- How to add/replace images (file naming conventions, size guidelines)
- How to add new portfolio/project entries
- How to update contact information
- Any content sections that are hardcoded and require developer assistance to change

#### Maintenance Guide
- How to create and restore backups
- How often to back up (and where backups are stored)
- Software/plugin updates schedule (if CMS used)
- SSL certificate renewal date and process
- Domain renewal date

#### Performance & Analytics
- How to access Google Analytics
- Key metrics to monitor (organic traffic, form submissions, page load time)
- How to read the monthly traffic report

#### Support & Ongoing Work
- Agency contact information for support requests
- What's included in any ongoing retainer (if applicable)
- Typical timeline for change requests

### 2. Asset Inventory

Produce a complete list of all project files delivered:
- All HTML pages
- All CSS files
- All JS files
- All image assets (with dimensions and purpose)
- All font files
- Any third-party licenses

### 3. Training Notes

If the client will be managing their own content, note:
- The 3 most common content updates they'll want to make
- Step-by-step instructions for each (with screenshots if possible)
- Things they should NOT change without developer assistance

### 4. Post-Launch Checklist for Client

Things the client needs to action after launch:
- [ ] Update business listings (Google Business Profile, Yelp, Yellow Pages) with new website URL
- [ ] Update email signatures with new website URL
- [ ] Update any print materials with new website URL
- [ ] Announce the new site on social media
- [ ] Ask recent clients for Google reviews (links the site to review signals)
- [ ] Verify Google Search Console ownership
